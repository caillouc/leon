# What's new in Leon

Each release, what changed for you, in short. The newest first.

## v0.7.0

- **Write while the agent works**: press Enter and your message waits, shown
  as "Queued" above the message box, then goes as soon as the answer ends.
- **Open in your editor**: "Open in Zed" (or VS Code) on a diff's file, in
  the diff's header and on the right pane's worktree opens it in your
  editor. Pick the editor in Settings.
- **Usage you can trust**: Doctor keeps each CLI's plan usage across restarts
  and says how old it is; Codex's is read as soon as Leon opens. Cost under
  an answer now shows only when the CLI runs on an API key, not on a
  subscription, and Codex's credits show when the account has some.
- **Roomier diffs**: line numbers take less space, a comment box spans the
  code's width (side by side too), and the drawer's file list can be resized.
  A pull request's diff says it is read-only, and where to comment instead.
- **Tidier screens**: the right pane shows on flows only, the bottom buttons
  take less room, and Claude's built-in connectors (AccuWeather, Booking.com,
  Uber) no longer crowd the Connectors list.
- Claude Code's "plan" permission mode is no longer offered.
